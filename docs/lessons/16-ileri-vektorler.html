Ders 16: İleri - Vektörler

📚 İleri Seviye ⏱️ 60 dakika 🎯 p5.Vector ile fizik simülasyonları

📐 Vektör Nedir?

Vektör, hem büyüklük (magnitude) hem de yön (direction) içeren matematiksel bir kavramdır. Programlamada vektörler genellikle iki veya üç boyutlu koordinatları temsil eder.

💡 Neden Vektör Kullanmalıyız?

Şimdiye kadar pozisyon ve hız için ayrı x ve y değişkenleri kullandık:

let x = 100, y = 200;
let hizX = 2, hizY = 3;

Vektörlerle bu daha temiz ve güçlü olur:

let pozisyon = createVector(100, 200);
let hiz = createVector(2, 3);

Vektör vs Skaler

Skaler (Sayı) Vektör
Sadece büyüklük Büyüklük + Yön
Örnek: 5, 10.5, -3 Örnek: (3, 4), (1, -2, 5)
Sıcaklık, kütle, zaman Konum, hız, kuvvet

🎯 p5.Vector Oluşturma

p5.js'de vektör oluşturmanın farklı yolları:

// 1. createVector() ile (en yaygın)
let v1 = createVector(100, 200);      // 2D vektör
let v2 = createVector(10, 20, 30);    // 3D vektör

// 2. p5.Vector.fromAngle() ile (açıdan)
let v3 = p5.Vector.fromAngle(HALF_PI);  // 90° yönünde birim vektör

// 3. p5.Vector.random2D() ile (rastgele yön)
let v4 = p5.Vector.random2D();  // Rastgele yönde birim vektör

// Vektör bileşenlerine erişim
console.log(v1.x);  // 100
console.log(v1.y);  // 200
console.log(v1.z);  // 0 (varsayılan)

Önemli Vektör Özellikleri

Özellik/Metod Açıklama
v.x, v.y, v.z Vektör bileşenleri
v.mag() Vektörün büyüklüğü (uzunluğu)
v.heading() Vektörün açısı (radyan)
v.copy() Vektörün kopyasını oluştur
v.set(x, y) Vektör değerlerini ayarla

➕ Vektör İşlemleri

p5.Vector, matematiksel işlemleri kolaylaştıran birçok metod sunar:

Temel İşlemler

let a = createVector(3, 4);
let b = createVector(1, 2);

// Toplama: a = a + b
a.add(b);           // a şimdi (4, 6)

// Çıkarma: a = a - b
a.sub(b);           // a şimdi (3, 4) geri döndü

// Skaler çarpma: a = a * 2
a.mult(2);          // a şimdi (6, 8)

// Skaler bölme: a = a / 2
a.div(2);           // a şimdi (3, 4) geri döndü

⚠️ Önemli: Orijinali Değiştirme

add(), sub(), mult(), div() metodları orijinal vektörü değiştirir! Orijinali korumak için önce kopyalayın: 

let sonuc = a.copy().add(b);  // a değişmez

Normalize ve Limit

let v = createVector(3, 4);

// Normalize: Yönü koru, büyüklüğü 1 yap
v.normalize();      // Şimdi büyüklük 1

// setMag: Belirli büyüklüğe ayarla
v.setMag(10);       // Şimdi büyüklük 10

// limit: Maksimum büyüklük sınırla
v.limit(5);         // Büyüklük en fazla 5 olur

Statik Metodlar

let a = createVector(3, 4);
let b = createVector(1, 2);

// Orijinalleri değiştirmeden işlem yap
let toplam = p5.Vector.add(a, b);     // Yeni vektör (4, 6)
let fark = p5.Vector.sub(a, b);       // Yeni vektör (2, 2)

// Mesafe hesapla
let mesafe = p5.Vector.dist(a, b);

// İki vektör arasındaki açı
let aci = a.angleBetween(b);

🏃 Hareket ve Hız

Vektörler hareket simülasyonu için idealdir. Temel formül: 

// Her frame'de:
pozisyon.add(hiz);          // Pozisyon = Pozisyon + Hız
hiz.add(ivme);              // Hız = Hız + İvme

Basit Hareket Modeli

let pozisyon;
let hiz;
let ivme;

function setup() {
  pozisyon = createVector(width/2, height/2);
  hiz = createVector(0, 0);
  ivme = createVector(0, 0);
}

function draw() {
  // Fareye doğru ivme (çekim)
  let fare = createVector(mouseX, mouseY);
  ivme = p5.Vector.sub(fare, pozisyon);
  ivme.setMag(0.5);  // İvme büyüklüğü
  
  // Fiziği uygula
  hiz.add(ivme);
  hiz.limit(10);     // Maksimum hız
  pozisyon.add(hiz);
  
  // Çiz
  circle(pozisyon.x, pozisyon.y, 20);
}

⚡ Kuvvetler ve Fizik

Newton'un ikinci yasası: F = m × a (Kuvvet = Kütle × İvme)

Bunu tersine çevirirsek: a = F / m (İvme = Kuvvet / Kütle)

Kuvvet Uygulama

class Parcacik {
  constructor(x, y, kutle) {
    this.pozisyon = createVector(x, y);
    this.hiz = createVector(0, 0);
    this.ivme = createVector(0, 0);
    this.kutle = kutle;
  }
  
  // Newton: a = F / m
  kuvvetUygula(kuvvet) {
    let ivmeKatkisi = p5.Vector.div(kuvvet, this.kutle);
    this.ivme.add(ivmeKatkisi);
  }
  
  guncelle() {
    this.hiz.add(this.ivme);
    this.pozisyon.add(this.hiz);
    this.ivme.mult(0);  // İvmeyi sıfırla (her frame yeniden hesaplanır)
  }
}

// Yerçekimi (sabit, aşağı doğru)
let yercekimi = createVector(0, 0.5);

// Rüzgar (yatay)
let ruzgar = createVector(0.1, 0);

// Sürtünme (harekete zıt yönde)
let surrtunme = hiz.copy();
surrtunme.mult(-1);
surrtunme.normalize();
surrtunme.mult(c);  // c: sürtünme katsayısı

// Çekim kuvveti (iki nesne arasında)
let yon = p5.Vector.sub(hedef.pozisyon, kaynak.pozisyon);
let mesafe = yon.mag();
let kuvvetBuyuklugu = (G * m1 * m2) / (mesafe * mesafe);
