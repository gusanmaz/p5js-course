Ders 8: Fonksiyonlar

📚 Orta-İleri Seviye ⏱️ 55 dakika 🎯 Kod Organizasyonu

Fonksiyon Nedir ve Neden Önemli?

Fonksiyon, belirli bir görevi yerine getiren, yeniden kullanılabilir kod bloğudur. Kodunuzu düzenli tutar ve tekrarı önler.

🎮 Oyun Programcısı İçin Neden Önemli?

Bir oyunda düşman çizme, mermi ateşleme, skor hesaplama gibi işlemler sürekli tekrarlanır. Her seferinde aynı kodu yazmak yerine, bir fonksiyon yazarsın ve istediğin yerde çağırırsın. Profesyonel oyunlarda binlerce fonksiyon bulunur!

🎯 Problem: Tekrar Eden Kod

Diyelim ki 5 farklı yerde yıldız çizmek istiyorsun:

❌ Fonksiyon Olmadan ✅ Fonksiyon ile 
// Yıldız 1 (50, 50)
stroke(255, 255, 0);
line(50, 35, 50, 65);
line(35, 50, 65, 50);
line(40, 40, 60, 60);
line(60, 40, 40, 60);

// Yıldız 2 (150, 80)
stroke(255, 255, 0);
line(150, 65, 150, 95);
line(135, 80, 165, 80);
line(140, 70, 160, 90);
line(160, 70, 140, 90);

// Yıldız 3, 4, 5...
// 20+ satır daha!

😫 Her yıldız için 5 satır!

 
function yildizCiz(x, y) {
  stroke(255, 255, 0);
  line(x, y-15, x, y+15);
  line(x-15, y, x+15, y);
  line(x-10, y-10, x+10, y+10);
  line(x+10, y-10, x-10, y+10);
}

// Kullanım - tek satır!
yildizCiz(50, 50);
yildizCiz(150, 80);
yildizCiz(200, 150);
yildizCiz(300, 100);
yildizCiz(250, 200);

🎉 Toplamda 12 satır!

Fonksiyonların 5 Büyük Faydası

  • 🔄 Yeniden Kullanım: Bir kez yaz, istediğin kadar çağır
  • 📖 Okunabilirlik: dusmanCiz() ne yaptığı açık
  • 🔧 Bakım Kolaylığı: Değişiklik tek yerde, her yere yansır
  • 🧩 Modülerlik: Büyük problemi küçük parçalara böl
  • 🐛 Hata Ayıklama: Sorun varsa tek bir yere bakarsın
💡 Zaten Fonksiyon Kullanıyordunuz!

setup(), draw(), circle(), background(), fill() - hepsi fonksiyon! p5.js size hazır fonksiyonlar sunar, şimdi kendi fonksiyonlarınızı yazmayı öğreneceksiniz.

Fonksiyon Tanımlama

function fonksiyonAdi() {
  // Yapılacak işler
}

// Çağırma:
fonksiyonAdi();

🧪 Deneyin

  • Yeni bir yildizCiz() fonksiyonu oluşturun
  • agacCiz() fonksiyonunu birden fazla kez çağırın

Parametreler (Argümanlar)

Fonksiyonlara değer göndererek farklı sonuçlar alabilirsiniz: 

function selamVer(isim) {
  console.log("Merhaba " + isim + "!");
}

selamVer("Ayşe");  // "Merhaba Ayşe!"
selamVer("Mehmet");  // "Merhaba Mehmet!"

Birden Fazla Parametre

function daireCiz(x, y, boyut, renk) {
  fill(renk);
  circle(x, y, boyut);
}

daireCiz(100, 200, 50, "red");
daireCiz(200, 200, 80, "blue");

return İfadesi

Fonksiyonlar değer döndürebilir. Bu değer başka yerlerde kullanılabilir: 

function topla(a, b) {
  return a + b;
}

let sonuc = topla(5, 3);  // sonuc = 8
let x = topla(10, topla(2, 3));  // x = 15
💡 return Kullanımı
  • return fonksiyonu hemen sonlandırır
  • Değer döndürmeyenler undefined döner
  • Birden fazla return olabilir (koşullarda)
