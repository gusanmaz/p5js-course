Ders 17: İleri - Trigonometri

📚 İleri Seviye ⏱️ 60 dakika 🎯 sin, cos ile yaratıcı animasyonlar

📐 Temel Kavramlar

Trigonometri, açılar ve uzunluklar arasındaki ilişkileri inceler. Grafik programlamada döngüsel hareketler, dalgalar ve karmaşık desenler için vazgeçilmezdir.

Açı Birimleri: Derece ve Radyan

🤔 Derece Nedir?

Günlük hayatta kullandığımız açı birimi derece'dir. Bir tam dönüş 360°'dir. Çeyrek dönüş 90°, yarım dönüş 180° demektir. Pusula, saat, pergel - hepsi derece kullanır.

🔄 Radyan Nedir?

Radyan, matematikteki "doğal" açı birimidir. Bir dairenin çevresinin yarıçapına bölümüne dayanır.

  • Bir tam dönüş = çemberin çevresi = 2π × yarıçap
  • Yani tam dönüş = 2π radyan ≈ 6.28 radyan
  • Yarım dönüş = π radyan ≈ 3.14 radyan
  • Çeyrek dönüş = π/2 radyan ≈ 1.57 radyan

Neden radyan? Matematik ve fizikteki formüller radyanla çok daha basit olur. p5.js varsayılan olarak radyan kullanır çünkü sin/cos hesaplamaları radyanla yapılır.

📐 Dönüşüm Formülü

360° = 2π radyan olduğundan:

  • Derece → Radyan: radyan = derece × (π / 180)
  • Radyan → Derece: derece = radyan × (180 / π)

p5.js'te radians() ve degrees() fonksiyonlarıyla kolayca dönüşüm yapabilirsiniz.

📊 Derece - Radyan Karşılaştırma Tablosu

🧭 Konum 📐 Derece 🔢 Radyan 💻 p5.js
➡️ Sağ (Başlangıç) 0° 0 0
⬇️ Aşağı (Çeyrek) 90° π/2 ≈ 1.57 HALF_PI
⬅️ Sol (Yarım) 180° π ≈ 3.14 PI
⬆️ Yukarı (Üç Çeyrek) 270° 3π/2 ≈ 4.71 PI + HALF_PI
🔄 Tam Dönüş 360° 2π ≈ 6.28 TWO_PI

💡 Hatırlatma: p5.js'te Açı Yönü

p5.js'te açılar sağdan başlar ve saat yönünde artar (normal matematiğin tersi). Yani 90° aşağıyı, 270° yukarıyı gösterir. 

// Açı modu ayarlama
angleMode(DEGREES);  // Derece kullan (0-360) - öğrenmesi kolay
angleMode(RADIANS);  // Radyan kullan (varsayılan) - matematiksel

// Dönüşüm fonksiyonları
let rad = radians(90);   // 90° → 1.57 rad (HALF_PI)
let deg = degrees(PI);   // π rad → 180°

// Örnek: 45 derecelik bir açı
let aci45_derece = 45;
let aci45_radyan = radians(45);  // ≈ 0.785
let aci45_pi = PI / 4;           // Aynı değer!

📊 sin() ve cos() Fonksiyonları

sin() ve cos() fonksiyonları bir açı alır ve -1 ile 1 arasında bir değer döndürür. Bu basit özellik inanılmaz derecede güçlü efektler oluşturmanızı sağlar.

💡 Temel Formül

Bir daire üzerindeki noktanın koordinatları:

x = merkezX + yaricap * cos(aci)
y = merkezY + yaricap * sin(aci)

sin() ve cos() Özellikleri

  • Her ikisi de -1 ile 1 arasında değer döndürür
  • Periyodik: Her 2π (360°) de bir tekrar eder
  • Düzgün: Değerler yumuşak geçişler yapar
  • cos(), sin()'den 90° önde gider

⭕ Daire Üzerinde Hareket

Trigonometrinin en yaygın kullanımı dairesel harekettir. Bir nokta bir daire etrafında dönerken sin ve cos ile pozisyonunu hesaplarız. 

let aci = 0;
let yaricap = 100;

function draw() {
  // Açıyı artır (döndür)
  aci += 0.02;
  
  // Daire üzerindeki nokta
  let x = width/2 + yaricap * cos(aci);
  let y = height/2 + yaricap * sin(aci);
  
  circle(x, y, 20);
}

🌊 Dalga Desenleri

Sin fonksiyonu doğal olarak dalga şekli oluşturur. Bu özellik animasyonlarda, ses görselleştirmede ve dekoratif desenlerde çok kullanılır.

Dalga Parametreleri

Parametre Etki Formül
Genlik (Amplitude) Dalganın yüksekliği genlik * sin(x)
Frekans (Frequency) Dalga sıklığı sin(x * frekans)
Faz (Phase) Dalganın kaydırılması sin(x + faz) 
// Dalga formülü
y = merkezY + genlik * sin(x * frekans + faz)

// Örnek: Animasyonlu dalga
y = height/2 + 50 * sin(x * 0.05 + frameCount * 0.1)

🎯 Kutupsal Koordinatlar

Normal (Kartezyen) koordinatlarda nokta (x, y) olarak tanımlanır. Kutupsal koordinatlarda ise (r, θ) - yarıçap ve açı ile tanımlanır. 

// Kutupsal → Kartezyen dönüşümü
x = r * cos(theta)
y = r * sin(theta)

// Kartezyen → Kutupsal dönüşümü
r = sqrt(x*x + y*y)    // veya: dist(0, 0, x, y)
theta = atan2(y, x)    // Açı

💡 Neden Kutupsal Koordinatlar?

Spiral, çiçek, yıldız gibi dairesel simetrik şekiller kutupsal koordinatlarla çok daha kolay tanımlanır. Yarıçapı açıya göre değiştirerek harika desenler elde edilir.

Popüler Kutupsal Formüller

Şekil Formül
Daire r = sabit
Spiral r = a * θ
Gül (Rose) r = cos(n * θ)
Kardiyoid r = a * (1 + cos(θ))
Lemniskat r² = a² * cos(2θ)
