🏹 Arrow Functions (Ok Fonksiyonları)

Modern JavaScript'te fonksiyonları daha kısa yazmanın bir yolu var: Arrow Functions (Lambda fonksiyonları olarak da bilinir).

Geleneksel vs Arrow Function

Geleneksel Fonksiyon Arrow Function 
function topla(a, b) {
  return a + b;
}
 
const topla = (a, b) => {
  return a + b;
};
 
function kare(x) {
  return x * x;
}
 
const kare = x => x * x;
Tek satır ve tek parametre için ultra kısa!		 
function selamla() {
  return "Merhaba!";
}
 
const selamla = () => "Merhaba!";
💡 Ne Zaman Kullanmalı?
  • Kısa işlemler için arrow function kullanın
  • Callback fonksiyonlar (forEach, map, filter içinde) için ideal
  • setup() ve draw() gibi p5.js fonksiyonlarını geleneksel yazın

🔄 forEach ve Modern Dizi Metodları

Diziler üzerinde işlem yapmak için for döngüsü yerine daha modern ve okunabilir metodlar kullanabilirsiniz.

forEach - Dizi Elemanlarını Gezme

for Döngüsü forEach Metodu 
let renkler = ["kırmızı", "yeşil", "mavi"];

for (let i = 0; i < renkler.length; i++) {
  console.log(renkler[i]);
}
 
let renkler = ["kırmızı", "yeşil", "mavi"];

renkler.forEach(renk => {
  console.log(renk);
});
Daha temiz ve okunabilir!

Diğer Faydalı Dizi Metodları

Metod Açıklama Örnek
forEach() Her eleman için bir fonksiyon çalıştırır dizi.forEach(x => console.log(x))
map() Her elemanı dönüştürüp yeni dizi oluşturur [1,2,3].map(x => x * 2) → [2,4,6]
filter() Koşula uyanları yeni diziye alır [1,2,3,4].filter(x => x > 2) → [3,4]
find() Koşula uyan ilk elemanı döndürür [1,5,10].find(x => x > 3) → 5
reduce() Tüm elemanları tek değere indirger [1,2,3].reduce((t,x) => t+x, 0) → 6

⏰ Zamanlayıcılar (setTimeout & setInterval)

Belirli bir süre sonra veya düzenli aralıklarla kod çalıştırmak istediğinizde zamanlayıcı fonksiyonlarını kullanabilirsiniz.

Fonksiyon Ne Yapar? Örnek
setTimeout(fn, ms) Belirtilen süre sonra bir kez çalışır 
setTimeout(() => {
  console.log("3 saniye geçti!");
}, 3000);
setInterval(fn, ms) Belirtilen aralıklarla sürekli çalışır 
setInterval(() => {
  console.log("Her 1 saniyede!");
}, 1000);
clearTimeout(id) setTimeout'u iptal eder let id = setTimeout(...); clearTimeout(id);
clearInterval(id) setInterval'ı durdurur let id = setInterval(...); clearInterval(id);
⚠️ p5.js'de Zamanlayıcı Kullanımı

p5.js zaten draw() fonksiyonunu saniyede ~60 kez çağırır. frameCount ve mod operatörü (%) ile çoğu zamanlama işini yapabilirsiniz: 

// Her 60 karede bir (yaklaşık 1 saniye)
if (frameCount % 60 == 0) {
  // Her saniye yapılacak iş
}

🔄 Transformasyonlar (translate, rotate, scale)

Şekilleri döndürmek, kaydırmak veya boyutlandırmak için transformasyon fonksiyonlarını kullanırız. Bu fonksiyonlar koordinat sistemini değiştirir.

Fonksiyon Ne Yapar? Örnek
translate(x, y) Koordinat merkezini (0,0) kaydırır translate(200, 200); → Merkez artık (200,200)
rotate(açı) Koordinat sistemini döndürür (radyan) rotate(PI/4); → 45 derece döndür
scale(s) Koordinat sistemini ölçekler scale(2); → Her şey 2 kat büyük
angleMode(DEGREES) Açıları derece olarak kullanmak için angleMode(DEGREES); rotate(45);

Önemli: Transformasyon Sırası

Transformasyonlar sırayla uygulanır ve birbirine eklenir. Önce translate, sonra rotate yaparsanız, döndürme yeni merkez etrafında olur.

📦 push() ve pop() - Durum Kaydetme

Transformasyonlar kalıcıdır - bir kez translate() yaparsanız, sonraki tüm çizimler etkilenir. push() ve pop() ile mevcut durumu kaydedip geri yükleyebilirsiniz.

Fonksiyon Ne Yapar?
push() Mevcut çizim ayarlarını kaydeder (renk, stroke, transformasyonlar)
pop() Son kaydedilen duruma geri döner

Neden Gerekli?

// ❌ YANLIŞ: Transformasyonlar birikir
function draw() {
  translate(200, 200);
  rotate(frameCount * 0.01);  // Her karede daha çok döner!
  rect(0, 0, 50, 50);
}

// ✅ DOĞRU: Her karede sıfırdan başla
function draw() {
  background(30);
  push();                      // Durumu kaydet
  translate(200, 200);
  rotate(frameCount * 0.01);
  rect(0, 0, 50, 50);
  pop();                       // Duruma geri dön
}
💡 İpucu: İç İçe push/pop

push() ve pop() iç içe kullanılabilir. Her push() için bir pop() olmalıdır.
