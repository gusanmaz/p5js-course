Ders 11: Stringler (Metinler)

📚 Orta Seviye ⏱️ 45 dakika 🎯 Metin işleme ve karakter dizileri

📝 String Nedir?

String, programlamada metinleri temsil eden veri tipidir. Türkçe'de "karakter dizisi" veya "metin" olarak da adlandırılır.

🔤 String = Karakter Dizisi

String aslında karakterlerin sıralı bir dizisidir. "Merhaba" stringi 7 karakterden oluşur: 'M', 'e', 'r', 'h', 'a', 'b', 'a'. Her karakterin bir indeks (sıra numarası) vardır ve indeksler 0'dan başlar.

String Oluşturma Yolları

📝

Üç Farklı Tırnak Türü

// 1. Tek tırnak (')
let isim = 'Ahmet';

// 2. Çift tırnak (")
let soyisim = "Yılmaz";

// 3. Backtick (`) - Template Literal
let mesaj = `Merhaba ${isim}!`;  // Değişken gömebilirsin!

// Hepsi aynı sonucu verir:
let s1 = 'Merhaba';
let s2 = "Merhaba";
let s3 = `Merhaba`;
console.log(s1 === s2);  // true
console.log(s2 === s3);  // true

💡 Hangisini Kullanmalı?

  • Tek tırnak: Basit metinler için (en yaygın)
  • Çift tırnak: İçinde tek tırnak varsa: "It's working!"
  • Backtick: Değişken gömmek veya çok satırlı metin için

String Uzunluğu: .length

📏

Kaç Karakter Var?

let metin = "Merhaba";
console.log(metin.length);  // 7

let bosluklu = "Merhaba Dünya";
console.log(bosluklu.length);  // 13 (boşluk da sayılır!)

let bos = "";
console.log(bos.length);  // 0

🔍 Karakterlere Erişim

String içindeki her karaktere indeks numarası ile erişebilirsin. İndeksler 0'dan başlar!

📊 String İndeks Tablosu

Karakter M e r h a b a
İndeks 0 1 2 3 4 5 6
Sondan -7 -6 -5 -4 -3 -2 -1
🎯

Karaktere Erişim Yöntemleri

let metin = "Merhaba";

// Yöntem 1: Köşeli parantez (en yaygın)
console.log(metin[0]);     // "M" (ilk karakter)
console.log(metin[1]);     // "e"
console.log(metin[6]);     // "a" (son karakter)
console.log(metin[7]);     // undefined (yok!)

// Yöntem 2: charAt() metodu
console.log(metin.charAt(0));   // "M"
console.log(metin.charAt(3));   // "h"

// Son karaktere erişim
let son = metin[metin.length - 1];  // "a"
console.log(son);

// at() metodu ile negatif indeks (modern JS)
console.log(metin.at(-1));   // "a" (son)
console.log(metin.at(-2));   // "b" (sondan ikinci)

⚠️ Stringler Değiştirilemez (Immutable)

JavaScript'te stringler değiştirilemez (immutable). Tek bir karakteri değiştiremezsin: 

let metin = "Merhaba";
metin[0] = "S";        // ÇALIŞMAZ!
console.log(metin);    // Hâlâ "Merhaba"

// Bunun yerine yeni string oluştur:
metin = "S" + metin.slice(1);  // "Serhaba"

🛠️ String Metodları

JavaScript stringleri çok sayıda kullanışlı metod sunar. İşte en önemlileri:

🔄 Dönüştürme Metodları

Metod Açıklama Örnek Sonuç
toUpperCase() Tüm harfleri büyük yapar "merhaba".toUpperCase() "MERHABA"
toLowerCase() Tüm harfleri küçük yapar "MERHABA".toLowerCase() "merhaba"
trim() Baş/son boşlukları siler " merhaba ".trim() "merhaba"
repeat(n) n kez tekrarlar "ha".repeat(3) "hahaha"

🔍 Arama Metodları

Metod Açıklama Örnek Sonuç
includes(str) İçeriyor mu? (true/false) "merhaba".includes("hab") true
startsWith(str) Bununla başlıyor mu? "merhaba".startsWith("mer") true
endsWith(str) Bununla bitiyor mu? "merhaba".endsWith("ba") true
indexOf(str) Nerede? (indeks, yoksa -1) "merhaba".indexOf("hab") 3

✂️ Kesme ve Birleştirme

Metod Açıklama Örnek Sonuç
slice(start, end) Parça kes (end dahil değil) "merhaba".slice(0, 3) "mer"
substring(start, end) slice gibi (negatif yok) "merhaba".substring(3, 6) "hab"
split(ayraç) Diziye böler "a,b,c".split(",") ["a", "b", "c"]
replace(eski, yeni) İlk eşleşmeyi değiştirir "merhaba".replace("a", "X") "merhXba"
replaceAll(eski, yeni) Tümünü değiştirir "merhaba".replaceAll("a", "X") "merhXbX"
💡

Metodları Zincirleme (Chaining)

// Metodları art arda kullanabilirsin
let metin = "   MERHABA DÜNYA   ";

let sonuc = metin
  .trim()           // "MERHABA DÜNYA"
  .toLowerCase()    // "merhaba dünya"
  .replace(" ", "-");  // "merhaba-dünya"

console.log(sonuc);  // "merhaba-dünya"

⚖️ String Karşılaştırma

Eşitlik Kontrolü

🔍

== vs === ile Karşılaştırma

let s1 = "merhaba";
let s2 = "merhaba";
let s3 = "Merhaba";
let s4 = "MERHABA";

// Eşitlik kontrolü (büyük/küçük harf duyarlı!)
console.log(s1 === s2);  // true (aynı)
console.log(s1 === s3);  // false (M ≠ m)
console.log(s1 === s4);  // false (farklı)

// Büyük/küçük harf duyarsız karşılaştırma
console.log(s1.toLowerCase() === s3.toLowerCase());  // true
console.log(s1.toLowerCase() === s4.toLowerCase());  // true

📖 Alfabetik Sıralama

JavaScript'te stringler Unicode değerlerine göre karşılaştırılır. <, >, <=, >= operatörleri kullanılabilir.

Karşılaştırma Sonuç Açıklama
"a" < "b" true 'a' alfabede 'b'den önce
"a" < "A" false Küçük harfler büyük harflerden sonra (Unicode)
"elma" < "armut" false 'e' > 'a'
"abc" < "abd" true İlk farklı karakter: 'c' < 'd'
"ab" < "abc" true Kısa olan önce gelir

🌍 localeCompare() - Dile Göre Sıralama

🇹🇷

Türkçe Alfabetik Sıralama

// Normal karşılaştırma (Unicode - Türkçe için sorunlu)
console.log("ç" > "d");  // true (yanlış! ç, d'den önce gelmeli)

// localeCompare ile doğru Türkçe sıralama
// Döndürdüğü değerler: -1 (önce), 0 (eşit), 1 (sonra)
console.log("ç".localeCompare("d", "tr"));  // -1 (ç önce)
console.log("ş".localeCompare("t", "tr"));  // -1 (ş önce)
console.log("ı".localeCompare("i", "tr"));  // -1 (ı önce)

// Dizi sıralama örneği
let meyveler = ["elma", "çilek", "armut", "şeftali", "üzüm"];
meyveler.sort((a, b) => a.localeCompare(b, "tr"));
console.log(meyveler);
// ["armut", "çilek", "elma", "şeftali", "üzüm"]

💡 Türkçe Karakterler

Türkçe sıralama için localeCompare("tr") kullan. Bu şekilde ç, ğ, ı, ö, ş, ü karakterleri doğru sıralanır.

🔁 Döngü ile Harfleri Gezme

String bir karakter dizisi olduğu için, döngü ile tüm harfleri gezebilirsin.

🔄

3 Farklı Yöntem

let metin = "Merhaba";

// Yöntem 1: Klasik for döngüsü
for (let i = 0; i < metin.length; i++) {
  console.log(i + ": " + metin[i]);
}
// 0: M, 1: e, 2: r, 3: h, 4: a, 5: b, 6: a

// Yöntem 2: for...of döngüsü (daha modern)
for (let harf of metin) {
  console.log(harf);
}
// M, e, r, h, a, b, a

// Yöntem 3: split + forEach
metin.split("").forEach((harf, index) => {
  console.log(`${index}. harf: ${harf}`);
});

📊 Karakter Sayma Örneği

🔢

Belirli Karakteri Sayma

function karakterSay(metin, aranan) {
  let sayac = 0;
  for (let harf of metin) {
    if (harf === aranan) {
      sayac++;
    }
  }
  return sayac;
}

console.log(karakterSay("merhaba", "a"));  // 2
console.log(karakterSay("mississippi", "s"));  // 4
console.log(karakterSay("hello world", "l"));  // 3

// Alternatif: split ile
function karakterSay2(metin, aranan) {
  return metin.split(aranan).length - 1;
}
console.log(karakterSay2("merhaba", "a"));  // 2

🔀 String Tersine Çevirme

↔️

Palindrom Kontrolü

// String'i tersine çevir
function tersCevir(metin) {
  let sonuc = "";
  for (let i = metin.length - 1; i >= 0; i--) {
    sonuc += metin[i];
  }
  return sonuc;
}

// Veya daha kısa yol:
function tersCevir2(metin) {
  return metin.split("").reverse().join("");
}

console.log(tersCevir("merhaba"));  // "abahrem"
console.log(tersCevir2("merhaba")); // "abahrem"

// Palindrom kontrolü (tersten de aynı okunan)
function palindromMu(metin) {
  metin = metin.toLowerCase().replace(/ /g, "");
  return metin === tersCevir2(metin);
}

console.log(palindromMu("kayak"));     // true
console.log(palindromMu("Ana"));       // true
console.log(palindromMu("merhaba"));   // false

🎨 p5.js ile String Kullanımı

p5.js'te stringler özellikle text() fonksiyonu ile ekrana metin yazdırmak için kullanılır.

📝

text() Fonksiyonu

// Temel kullanım
text("Merhaba", x, y);

// Metin ayarları
textSize(32);           // Yazı boyutu
textAlign(CENTER);      // Hizalama: LEFT, CENTER, RIGHT
textFont("Arial");      // Font
fill(255);              // Yazı rengi

// Metin genişliği ölçme
let genislik = textWidth("Merhaba");

// Çok satırlı metin (kutu içinde)
text("Uzun bir metin...", x, y, genislik, yükseklik);
