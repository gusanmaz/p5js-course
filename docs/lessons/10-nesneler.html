Ders 10: Nesneler ve Sınıflar

📚 İleri Seviye ⏱️ 70 dakika 🎯 Nesne Yönelimli Programlama

🧠 Nesne Yönelimli Programlama (OOP) Nedir?

📚 Bu Konuyu Neden Öğreniyoruz?

Şu ana kadar değişkenler, fonksiyonlar, diziler öğrendik. Ama programlar büyüdükçe kodları organize etmek zorlaşır. OOP, kodlarımızı gerçek dünya gibi "nesneler" şeklinde düzenlememizi sağlar.

🎯 OOP'nin Temel Felsefesi

OOP, 1960'larda ortaya çıkmış ve bugün en yaygın programlama paradigmasıdır. Temel fikir şu: Gerçek dünyayı modellemek için, gerçek dünyadaki gibi düşünelim.

Düşün: Etrafına bak. Her şey bir "nesne" - telefon, masa, kalem, araba... Her nesnenin özellikleri (renk, boyut, ağırlık) ve davranışları (telefon arayabilir, araba gidebilir) var.

OOP'de de aynı mantıkla kod yazıyoruz:

  • Özellikler (İng: Properties): Nesnenin taşıdığı veriler - this.x, this.renk
  • Davranışlar (İng: Methods): Nesnenin yapabileceği işlemler - hareket(), goster()

😱 Problem: Kodlar Karışıyor!

Düşün: Bir oyun yapıyorsun ve 50 tane düşman var. Her birinin x, y, sağlık, hız değeri var:

// 😱 KARİŞIK YOL - Her şey ayrı ayrı
let dusman1_x = 100;
let dusman1_y = 50;
let dusman1_saglik = 100;
let dusman1_hiz = 2;

let dusman2_x = 200;
let dusman2_y = 80;
let dusman2_saglik = 100;
let dusman2_hiz = 3;

// 50 düşman için 200 değişken! 🤯
// ✅ NESNE YOL - Her şey bir arada
let dusman1 = { x: 100, y: 50, saglik: 100, hiz: 2 };
let dusman2 = { x: 200, y: 80, saglik: 100, hiz: 3 };

// Daha temiz! Ama hala tekrar var...
// 🎯 SINIF YOL - Şablon kullan, istediğin kadar üret!
class Dusman {
  constructor(x, y) {
    this.x = x;
    this.y = y;
    this.saglik = 100;
    this.hiz = random(1, 3);
  }
}

let dusmanlar = [];
for (let i = 0; i < 50; i++) {
  dusmanlar.push(new Dusman(random(width), random(height)));
}
// 50 düşman 5 satır kodla! 🎉

OOP'nin Temel Mantığı

🏭 Sınıf (Class)

Bir fabrika planı gibi. "Top nasıl olmalı?" sorusunun cevabı.

Örnek: Top sınıfı - x, y, renk, hız bilgilerini içerir

🎾 Nesne (Object)

O plandan üretilen gerçek ürün. Her biri bağımsız.

Örnek: top1, top2 - aynı sınıftan farklı toplar

📊 Özellik (Property)

Nesnenin sahip olduğu veriler.

Örnek: x, y, renk, boyut değerleri

⚙️ Metod (Method)

Nesnenin yapabildiği işlemler.

Örnek: hareket(), goster(), zipla() fonksiyonları

📖 OOP Terimler Sözlüğü

Programlamada İngilizce terimler çok kullanılır. İşte karşılaşacağın tüm OOP terimleri:

İngilizce Türkçe Açıklama Örnek
class Sınıf Nesne şablonu, plan class Top { }
object Nesne Sınıftan üretilen örnek let top = new Top()
instance Örnek, Örnek Nesne Bir sınıfın somut örneği top1, top2 birer instance
constructor Kurucu, Yapıcı Nesne oluşurken çalışan fonksiyon constructor(x, y) { }
property Özellik, Nitelik Nesnenin sahip olduğu veri this.x = 100
method Metod, Yöntem Nesnenin fonksiyonu goster() { }
this Bu, Kendisi O anki nesneye referans this.x += this.hiz
new Yeni Yeni nesne oluşturma komutu new Top(100, 200)
inheritance Kalıtım, Miras Bir sınıfın başkasından özellik alması class Araba extends Arac
extends Genişletir Kalıtım için kullanılan kelime class X extends Y

İsimlendirme Kuralları

Stil Kullanım Yeri Örnekler
PascalCase Sınıf isimleri Top, DusmanKarakter, ZiplayanTop
camelCase Değişken ve fonksiyonlar topHiz, dusmanSaglik, karakterHareket()
UPPER_CASE Sabitler (değişmeyen değerler) MAX_SKOR, OYUN_GENISLIK

Nesne Nedir?

Nesne, ilişkili verileri ve fonksiyonları bir arada tutan veri yapısıdır. Gerçek dünyadaki nesneler gibi özellikleri ve davranışları vardır.

🧠 Gerçek Hayat Benzetmesi

Bir araba nesnesi düşünün:
Özellikler (Properties): renk, hız, yakıt miktarı
Davranışlar (Methods): hızlan(), frenYap(), kornaCal()

Nesne vs Dizi

Dizi ve nesne arasındaki en büyük fark: dizide verilere sıra numarası ile, nesnede ise isim ile erişirsin. Bu da kodun okunabilirliğini çok artırır. 

// Dizi: sadece değerler (sıralı)
let top = [200, 150, 30, 2, -1];  // Ne anlama geliyor? 🤔
// top[0] neydi? x mi? y mi? Hafızada tutmak zor!

// Nesne: isimlendirilmiş özellikler (anlaşılır)
let top = {
  x: 200,        // X pozisyonu - net!
  y: 150,        // Y pozisyonu - net!
  yaricap: 30,   // Yarıçap - net!
  hizX: 2,       // X yönü hızı - net!
  hizY: -1       // Y yönü hızı - net!
};
// top.x diyince ne olduğu açık! ✅
// 6 ay sonra koda baktığında da anlarsın
💡 Ne Zaman Hangisi?

Dizi kullan: Benzer türde sıralı veriler için - puanlar, renkler listesi, koordinat dizisi
Nesne kullan: Farklı türde ilişkili veriler için - bir karakterin tüm özellikleri

Nesne Literal (Object Literal)

let ogrenci = {
  isim: "Ayşe",
  yas: 15,
  sinif: 9,
  notlar: [85, 92, 78]
};

// Erişim
console.log(ogrenci.isim);      // "Ayşe"
console.log(ogrenci["yas"]);    // 15

// Değiştirme
ogrenci.yas = 16;

// Yeni özellik ekleme
ogrenci.okul = "Anadolu Lisesi";

Sınıf (Class)

Sınıf, benzer nesneler oluşturmak için şablon görevi görür. Bir kez tanımla, istediğin kadar nesne oluştur!

Düşün: Bir araba fabrikası var. Fabrikanın planı (sınıf) bir tane, ama bu plandan binlerce araba (örnek/instance) üretebilirsin. Her araba aynı yapıda ama farklı renk, plaka, motor gücü olabilir. 

// SINIF TANIMI - Bu bir şablon, plan
class Top {
  // CONSTRUCTOR (KURUCU) FONKSİYON
  // "new Top()" dendiğinde otomatik çağrılır
  // Nesnenin ilk değerlerini ayarlar
  constructor(x, y, r) {
    // "this" = "şu an oluşturulan nesne"
    this.x = x;           // Parametre olarak gelen x
    this.y = y;           // Parametre olarak gelen y
    this.yaricap = r;     // Parametre olarak gelen yarıçap
    // Rastgele renk - her nesne için farklı olacak
    this.renk = color(random(255), random(255), random(255));
  }
  
  // METOD - Nesnenin yapabileceği işlem
  // Fonksiyon gibi ama "function" yazılmaz
  goster() {
    fill(this.renk);      // Bu nesnenin rengi
    circle(this.x, this.y, this.yaricap * 2);
  }
}

// NESNE OLUŞTURMA - Şablondan gerçek ürün
// "new" kelimesi yeni nesne oluşturur ve constructor'ı çağırır
let top1 = new Top(100, 200, 30);  // x=100, y=200, r=30
let top2 = new Top(300, 150, 50);  // Farklı değerlerle başka top
// top1 ve top2 bağımsız nesneler, birini değiştirmek diğerini etkilemez
💡 "this" Anahtar Kelimesi - Çok Önemli!

this, o anda çalışan nesneyi temsil eder. this.x "bu nesnenin x'i" anlamına gelir.

Örnek: top1.goster() çağrıldığında, this = top1 olur. top2.goster() çağrılınca this = top2 olur. Böylece aynı kod, hangi nesne için çağrıldıysa onun verilerini kullanır.

Metodlar

Metodlar, nesnenin yapabildiği işlemlerdir. Normal fonksiyonlar gibi çalışır ama o nesneye ait verilere this ile erişir.

Metod türleri:

  • Eylem metodları: Bir şey yapar - hareket(), saldir(), zipla()
  • Gösterim metodları: Nesneyi çizer - goster(), ciz()
  • Sorgulama metodları: Bilgi döndürür - yasiyorMu(), carpisiyorMu()
  • Değiştirme metodları: Özellikleri değiştirir - hasarAl(), iyiles()
class Canavar {
  constructor(x, y) {
    this.x = x;
    this.y = y;
    this.enerji = 100;
  }
  
  // EYLEM METODU - Parametre alır, nesneyi değiştirir
  hareket(dx, dy) {
    this.x += dx;       // x'i dx kadar artır
    this.y += dy;       // y'yi dy kadar artır
    this.enerji -= 1;   // Her harekette enerji azalır
  }
  
  // DEĞİŞTİRME METODU - Değer döndürür
  saldir() {
    console.log("Rawr! 🦖");
    return 10;  // Hasar değeri - bu değeri dışarıda kullanabilirsin
  }
  
  // SORGULAMA METODU - true/false döndürür
  yasiyorMu() {
    return this.enerji > 0;  // Enerji 0'dan büyükse true
  }
}

// Kullanım:
let canavar = new Canavar(100, 100);
canavar.hareket(10, 5);           // Canavarı hareket ettir
let hasar = canavar.saldir();     // Saldır, hasar değerini al
if (canavar.yasiyorMu()) { ... }  // Yaşıyor mu kontrol et
