📐 windowWidth & windowHeight

p5.js, tarayıcı penceresinin boyutlarını otomatik olarak takip eden iki önemli değişken sağlar:

Değişken Açıklama Benzer
windowWidth Tarayıcı penceresinin genişliği (piksel) CSS: 100vw
windowHeight Tarayıcı penceresinin yüksekliği (piksel) CSS: 100vh
width Canvas genişliği createCanvas'ta belirlenir
height Canvas yüksekliği createCanvas'ta belirlenir
displayWidth Ekranın tam genişliği Monitör çözünürlüğü
displayHeight Ekranın tam yüksekliği Monitör çözünürlüğü

💡 width vs windowWidth

width ve height canvas boyutlarıdır - siz belirlersiniz.
windowWidth ve windowHeight tarayıcı pencere boyutlarıdır - kullanıcıya bağlıdır.

🔄 windowResized() Fonksiyonu

Kullanıcı tarayıcı penceresini yeniden boyutlandırdığında windowResized() fonksiyonu otomatik olarak çağrılır. Bu fonksiyon içinde canvas'ı yeniden boyutlandırabilirsiniz. 

function setup() {
  // Pencere boyutunda canvas oluştur
  createCanvas(windowWidth, windowHeight);
}

function draw() {
  background(30);
  // Çizimler...
}

// Pencere boyutu değişince çağrılır
function windowResized() {
  // Canvas'ı yeni boyuta göre ayarla
  resizeCanvas(windowWidth, windowHeight);
  
  // Gerekirse diğer değişkenleri de güncelle
  console.log("Yeni boyut:", windowWidth, "x", windowHeight);
}

⚠️ Önemli Notlar

  • resizeCanvas() canvas içeriğini temizler
  • Nesne pozisyonlarını oransal olarak güncellemeniz gerekebilir
  • Çok sık resize işlemi performansı etkileyebilir

📏 Göreceli Konumlandırma

Responsive tasarımın anahtarı, sabit piksel değerleri yerine oransal değerler kullanmaktır. Bu sayede tasarımınız her ekran boyutunda doğru görünür.

Kötü Örnek (Sabit Değerler):

// ❌ Bu sadece 400x400 canvas'ta doğru görünür
circle(200, 200, 100);  // Merkez ve boyut sabit

İyi Örnek (Oransal Değerler):

// ✅ Her boyutta ortada görünür
circle(width/2, height/2, width * 0.25);
// width/2: Yatay merkez
// height/2: Dikey merkez
// width * 0.25: Canvas genişliğinin %25'i kadar çap

Sık Kullanılan Oranlar:

İfade Anlamı Kullanım
width/2 Yatay merkez Ortada hizalama
height/2 Dikey merkez Ortada hizalama
width * 0.1 %10 genişlik Kenar boşlukları
min(width, height) Küçük kenar Kare içeriği sığdırma
width/cols Sütun genişliği Grid sistemleri

🖥️ Tam Ekran Modu

p5.js'de fullscreen() fonksiyonu ile tam ekran modunu açıp kapatabilirsiniz. 

// Tam ekran modunu aç/kapat
fullscreen(true);   // Tam ekran yap
fullscreen(false);  // Normal moda dön

// Mevcut durumu öğren
let isFS = fullscreen();  // true veya false döner

// Toggle (değiştir)
fullscreen(!fullscreen());  // Mevcut durumun tersini yap

⚠️ Tarayıcı Kısıtlaması

Güvenlik nedeniyle tam ekran sadece kullanıcı etkileşimi (tıklama, tuş basma) sonucunda etkinleştirilebilir. setup() içinde otomatik olarak tam ekran yapamazsınız.

🎨 Responsive UI Tasarımı

Oyun veya uygulama arayüzlerinin farklı ekran boyutlarında düzgün görünmesi için bazı stratejiler:

1. Merkezi Referans Noktası

// Tüm konumları merkezden hesapla
let merkezX = width / 2;
let merkezY = height / 2;

// Butonlar merkeze göre konumlanır
rect(merkezX - 100, merkezY - 25, 200, 50);

2. Ölçekleme Faktörü

// Temel bir boyut belirle
let temelBoyut = min(width, height);
let olcek = temelBoyut / 400;  // 400px'lik tasarım için

// Tüm değerleri ölçekle
textSize(16 * olcek);
rect(x, y, 100 * olcek, 50 * olcek);

3. Breakpoint'ler (Kırılma Noktaları)

// Ekran boyutuna göre farklı düzen
if (width < 600) {
  // Mobil düzen: tek sütun
  dikeySirayla();
} else {
  // Masaüstü düzen: çok sütun
  yataySirayla();
}
