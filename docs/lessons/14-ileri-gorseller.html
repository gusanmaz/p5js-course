Ders 14: İleri - Görsel Yükleme

📚 İleri Seviye ⏱️ 45 dakika 🎯 Harici görselleri kullanma

⏳ preload() Fonksiyonu

p5.js'de harici dosyaları (görsel, ses, font vb.) yüklemek için özel bir fonksiyon kullanırız: preload(). Bu fonksiyon setup()'tan önce çalışır ve içindeki tüm dosyalar yüklenene kadar program bekler.

💡 Neden preload() Gerekli?

İnternetten bir görsel yüklemek zaman alır. Eğer setup() içinde yüklemeye çalışırsak, görsel henüz yüklenmeden kullanmaya çalışabiliriz ve hata alırız. preload() bu sorunu çözer. 

let img;  // Görsel değişkeni

// preload: setup'tan ÖNCE çalışır
function preload() {
  // Görsel yüklenene kadar program bekler
  img = loadImage('resim.jpg');
}

function setup() {
  createCanvas(400, 400);
  // Artık img kullanıma hazır!
}

function draw() {
  image(img, 0, 0);
}

⚠️ Önemli: CORS Kısıtlaması

Tarayıcılar güvenlik nedeniyle farklı sitelerden görsel yüklemeyi kısıtlayabilir (CORS). Bu yüzden örneklerimizde kod ile oluşturulan görseller veya createGraphics() kullanacağız. Kendi projelerinizde görselleri aynı klasöre koyarak bu sorunu çözebilirsiniz.

🖼️ loadImage() ile Görsel Yükleme

loadImage() fonksiyonu bir görsel dosyasını yükler ve bir p5.Image nesnesi döndürür. Bu nesne ile görselin boyutlarına erişebilir ve çeşitli işlemler yapabilirsiniz. 

// Temel kullanım
img = loadImage('resim.png');

// Callback fonksiyonları ile
img = loadImage('resim.png', 
  () => console.log('Yüklendi!'),     // Başarılı
  () => console.log('Hata oluştu!')   // Hata
);

// Görselin özellikleri
console.log(img.width);   // Genişlik
console.log(img.height);  // Yükseklik

✏️ image() ile Görsel Çizme

Yüklenen görseli canvas üzerine çizmek için image() fonksiyonunu kullanırız. Bu fonksiyon farklı parametrelerle esnek kullanım sağlar.

Kullanım Açıklama
image(img, x, y) Orijinal boyutta çiz
image(img, x, y, w, h) Belirli boyutta çiz
image(img, dx, dy, dw, dh, sx, sy, sw, sh) Kaynak bölgeden hedef bölgeye çiz (sprite sheet için)

📐 imageMode ve Boyutlandırma

rectMode() gibi, imageMode() da görselin referans noktasını belirler:

  • CORNER (varsayılan): Sol üst köşe referans
  • CENTER: Merkez referans
  • CORNERS: İki köşe koordinatı

🎨 tint() ile Renklendirme

tint() fonksiyonu görsellere renk filtresi uygular. Bu sayede görselleri renklendirebilir veya saydamlık ekleyebilirsiniz. 

// Renk filtresi
tint(255, 0, 0);    // Kırmızı ton
image(img, 0, 0);

// Saydamlık
tint(255, 128);     // %50 saydam
image(img, 0, 0);

// Hem renk hem saydamlık
tint(0, 150, 255, 200);  // Mavi ton, biraz saydam

// tint'i kaldır
noTint();

🔬 Piksel İşlemleri

p5.js ile görsellerin piksellerine erişebilir ve değiştirebilirsiniz. Bu özellik görüntü işleme, filtreler ve efektler için kullanılır. 

// Görselin piksellerini yükle
img.loadPixels();

// pixels dizisi: [R, G, B, A, R, G, B, A, ...]
// Her piksel 4 değer içerir

// (x, y) konumundaki piksele erişim
let index = (x + y * img.width) * 4;
let r = img.pixels[index];     // Kırmızı
let g = img.pixels[index + 1]; // Yeşil
let b = img.pixels[index + 2]; // Mavi
let a = img.pixels[index + 3]; // Alpha

// Pikseli değiştir
img.pixels[index] = 255;       // Kırmızıyı maksimum yap

// Değişiklikleri uygula
img.updatePixels();
