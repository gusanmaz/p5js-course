Ders 5: Etkileşim

📚 Orta Seviye ⏱️ 50 dakika 🎯 Kullanıcı Girdileri

Etkileşim Nedir ve Neden Önemli?

🎮 Oyun Programcısı İçin Neden Kritik?

Oyunları oyunlardan ayıran şey etkileşimdir! Fare ile nişan al, klavye ile zıpla, tıklama ile ateş et... Etkileşim olmadan sadece bir animasyon izlersin, oyun oynamazsın. Bu ders, oyuncuyu oyunun içine sokar!

🎯 Etkileşim Türleri

  • 🖱️ Fare: Konum takibi, tıklama, sürükleme
  • ⌨️ Klavye: Tuş basma, hareket kontrolü
  • 📱 Dokunmatik: Touch events (mobil)
  • 🎮 Gamepad: Joystick ve butonlar

Bu derste fare ve klavye etkileşimini öğreneceksiniz.

Fare Etkileşimi

p5.js, fare konumunu ve durumunu takip eden hazır değişkenler sunar. Bunları kullanarak etkileşimli projeler oluşturabilirsiniz.

Değişken Açıklama Kullanım
mouseX Farenin yatay konumu (X) circle(mouseX, 200, 50)
mouseY Farenin dikey konumu (Y) circle(200, mouseY, 50)
pmouseX, pmouseY Önceki karedeki fare konumu line(pmouseX, pmouseY, mouseX, mouseY)
mouseIsPressed Fare tuşu basılı mı? (true/false) if (mouseIsPressed) { ... }
mouseButton Hangi tuş basılı? if (mouseButton == LEFT) { ... }

🧪 Deneyin

  • Daire boyutunu fareye göre değiştirin: circle(mouseX, mouseY, mouseX/2)
  • pmouseX/pmouseY kullanarak çizgi çizin

Fare Olay Fonksiyonları

Belirli fare eylemlerinde otomatik çağrılan özel fonksiyonlar vardır:

Fonksiyon Ne Zaman Çalışır? Örnek
mousePressed() Fare tuşuna basıldığında (1 kez) 
function mousePressed() {
  renk = random(255);
}
mouseReleased() Fare tuşu bırakıldığında 
function mouseReleased() {
  surukleniyor = false;
}
mouseClicked() Tıklama tamamlandığında (bas + bırak) 
function mouseClicked() {
  skor++;
}
mouseMoved() Fare hareket ettiğinde (tuş basılı değilken) 
function mouseMoved() {
  mesaj = "Fare hareket etti!";
}

Klavye Etkileşimi

Klavye girişlerini algılamak için de hazır değişkenler vardır:

Değişken Açıklama Örnek
keyIsPressed Herhangi bir tuş basılı mı? (true/false) if (keyIsPressed) { hiz = 10; }
key Son basılan tuşun karakteri ('a', 'B', '5', ' ') if (key == 'a') { sola(); }
keyCode Özel tuşlar için (ok tuşları, Enter, vb.) if (keyCode == LEFT_ARROW) { x -= 5; }

Özel Tuş Kodları

Tuş Kodu Açıklama
UP_ARROW, DOWN_ARROWYukarı / Aşağı ok tuşları
LEFT_ARROW, RIGHT_ARROWSol / Sağ ok tuşları
ENTER, RETURNEnter tuşu
BACKSPACE, DELETESilme tuşları
SHIFT, CONTROL, ALTModifier tuşları
ESCAPEEsc tuşu

Klavye Olay Fonksiyonları

Fonksiyon Ne Zaman Çalışır? Örnek
keyPressed() Tuşa basıldığında (1 kez) 
function keyPressed() {
  if (key == ' ') atla();
}
keyReleased() Tuş bırakıldığında 
function keyReleased() {
  hiz = 0;
}
keyTyped() Karakter tuşu yazıldığında (özel tuşlar hariç) 
function keyTyped() {
  metin += key;
}
