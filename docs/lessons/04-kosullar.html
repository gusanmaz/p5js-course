Ders 4: Koşullar (if/else)

📚 Temel Kavram ⏱️ 45 dakika 🎯 Karar Yapıları

if Yapısı ve Neden Önemli?

if (eğer) ifadesi, programın belirli koşullara göre farklı davranışlar sergilemesini sağlar. Koşul doğruysa kod bloğu çalışır, değilse atlanır.

🎮 Oyun Programcısı İçin Neden Kritik?

Oyunlarda sürekli karar verilir: Düşmana çarptın mı? Zıplama tuşuna bastın mı? Canın bitti mi? Sınırı geçtin mi? Hepsi if ile kontrol edilir. if olmadan oyun yapılamaz!

🎯 Problem: Koşulsuz Kod

Koşul olmadan program hep aynı şeyi yapar:

❌ Koşul Olmadan ✅ if ile 
// Top her zaman aynı renk
fill(255, 0, 0);  // Kırmızı
circle(x, y, 50);

// Düşman her zaman hareket eder
x += hiz;  // Sınır kontrolü yok!

😫 Top sınırdan çıkar, hiç tepki veremez

 
// Fare üzerindeyse yeşil, değilse kırmızı
if (dist(mouseX, mouseY, x, y) < 25) {
  fill(0, 255, 0);  // Yeşil - hover!
} else {
  fill(255, 0, 0);  // Kırmızı
}
circle(x, y, 50);

// Sınır kontrolü
if (x > width) x = 0;  // Sarmala!

🎉 Etkileşimli ve kontrollü!

if'in 5 Büyük Kullanım Alanı

  • 🧱 Sınır Kontrolü: Ekrandan çıkma, zıplama
  • 💥 Çarpışma: Düşmana çarptın mı? Güç aldın mı?
  • 🎮 Girdi: Hangi tuşa basıldı?
  • 🏆 Oyun Durumu: Kazandın mı? Kaybettin mi?
  • 🎨 Görsel Değişim: Hover, seçim, hasar animasyonu
if (koşul) {
  // Koşul doğruysa (true) bu kod çalışır
}

Karşılaştırma Operatörleri

Koşullar oluşturmak için karşılaştırma operatörlerini kullanırız:

Operatör Anlamı Örnek Sonuç
== Eşit mi? 5 == 5 true
=== Tam eşit mi? (tip dahil) 5 === "5" false
!= Eşit değil mi? 5 != 3 true
!== Tam eşit değil mi? 5 !== "5" true
> Büyük mü? 10 > 5 true
< Küçük mü? 3 < 7 true
>= Büyük veya eşit mi? 5 >= 5 true
<= Küçük veya eşit mi? 4 <= 3 false
⚠️ = ile == Farkı
= Değer atama x = 5 x'e 5 değerini ata
== Karşılaştırma x == 5 x 5'e eşit mi?

Bu ikisini karıştırmak çok yaygın bir hatadır!

else ve else if

else (Değilse)

Koşul yanlışsa çalışacak alternatif kod bloğu:

if (kosul) {
  // Koşul doğruysa
} else {
  // Koşul yanlışsa
}

else if (Değilse Eğer)

Birden fazla koşulu sırayla kontrol etmek için:

if (kosul1) {
  // Koşul1 doğruysa
} else if (kosul2) {
  // Koşul1 yanlış, koşul2 doğruysa
} else if (kosul3) {
  // Koşul1 ve 2 yanlış, koşul3 doğruysa
} else {
  // Hiçbiri doğru değilse
}

Mantıksal Operatörler

Gerçek hayatta kararlar nadiren tek bir koşula bağlıdır. "Hava güzelse VE param varsa dışarı çıkarım" gibi. Programlamada da birden fazla koşulu birleştirmek için mantıksal operatörler kullanırız.

🔗 Operatörler

Operatör Adı Açıklama Örnek
&& VE (AND) Her iki koşul da doğru olmalı x > 0 && x < 100
|| VEYA (OR) En az bir koşul doğru olmalı key == 'a' || key == 'A'
! DEĞİL (NOT) Koşulu tersine çevirir !oyunBitti

📊 Doğruluk Tabloları (Truth Tables)

Mantıksal operatörlerin nasıl çalıştığını anlamak için doğruluk tabloları kullanılır. Bu tablolar tüm olası giriş kombinasyonları için çıktıyı gösterir.

VE (&&) - AND

İkisi de true olmalı

A B A && B
false false false
false true false
true false false
true true true ✓

VEYA (||) - OR

En az biri true olmalı

A B A || B
false false false
false true true ✓
true false true ✓
true true true ✓

DEĞİL (!) - NOT

Değeri tersine çevirir

A !A
false true
true false

💡 Hatırlatıcı İpuçları

  • && (VE): "Pessimist" gibi düşün - bir tanesi bile false ise sonuç false
  • || (VEYA): "Optimist" gibi düşün - bir tanesi bile true ise sonuç true
  • ! (DEĞİL): Kapıdaki "itiniz/çekiniz" gibi - ne ise tersini yap

🧩 Kompleks İfadeler

Birden fazla operatörü birleştirerek karmaşık koşullar oluşturabilirsiniz. Parantez kullanarak öncelik belirleyin.

💡

Kompleks İfade Örnekleri

// Örnek 1: Oyun karakteri hareket edebilir mi?
// Oyun bitmemişse VE (canı varsa VEYA kalkanı varsa)
let hareketEdebilir = !oyunBitti && (can > 0 || kalkanVar);

// Örnek 2: Fare dikdörtgenin içinde mi?
// x hem soldan büyük HEM sağdan küçük VE
// y hem üstten büyük HEM alttan küçük
if (mouseX > sol && mouseX < sag && mouseY > ust && mouseY < alt) {
  // Fare dikdörtgenin içinde!
}

// Örnek 3: Kullanıcı giriş yapabilir mi?
// (Email doğru VE şifre doğru) VEYA admin ise
let girisYapabilir = (emailDogru && sifreDogru) || adminMi;

// Örnek 4: Hafta içi çalışma saatleri
// Hafta içi (Pzt-Cum) VE saat 9-17 arası
let calismaSaati = gunHaftaIci && (saat >= 9 && saat < 17);

// Örnek 5: Yaş kontrolü (18-65 arası ve emekli değil)
let calisabilir = (yas >= 18 && yas <= 65) && !emekli;

📊 Kompleks İfade Doğruluk Tablosu

!oyunBitti && (can > 0 || kalkanVar) ifadesinin tüm olası durumları:

oyunBitti can > 0 kalkanVar !oyunBitti (can>0 || kalkan) Sonuç
false false false true false false ❌
false false true true true true ✓
false true false true true true ✓
false true true true true true ✓
true false false false false false ❌
true false true false true false ❌
true true false false true false ❌
true true true false true false ❌

💡 Yorum: Oyun bitmişse (oyunBitti = true), canın veya kalkanın olması fark etmez - hareket edemezsin!

⚠️ Operatör Önceliği

JavaScript'te mantıksal operatör önceliği:

  1. ! (NOT) - En yüksek öncelik
  2. && (AND)
  3. || (OR) - En düşük öncelik

Karışıklığı önlemek için parantez kullanın: (A || B) && C
