Ders 9: Diziler (Arrays)

📚 Orta-İleri Seviye ⏱️ 60 dakika 🎯 Veri Yapıları

Dizi Nedir ve Neden Önemli?

Dizi (Array), birden fazla değeri tek bir değişkende saklayan veri yapısıdır. Alışveriş listesi gibi düşünebilirsiniz - tek bir kağıtta birçok ürün yazılı!

Normalde her değer için ayrı değişken tanımlarsın: let sayi1 = 10;, let sayi2 = 20;... Ama 100 sayı için 100 değişken mi tanımlayacaksın? İşte diziler tam bu sorunu çözer: let sayilar = [10, 20, 30, ...];

🎮 Oyun Programcısı İçin Neden Kritik?

Oyunlarda çok sayıda nesne var: düşmanlar, mermiler, güç-uplar, parçacıklar, engeller... Her biri için ayrı değişken tanımlamak imkansız! Diziler sayesinde 100 mermiyi tek bir mermiler değişkeninde tutabilirsin.

🎯 Problem: Çok Fazla Değişken!

5 tane düşen yıldız animasyonu yapmak istiyorsun:

❌ Dizi Olmadan ✅ Dizi ile 
// 5 yıldız için 10 değişken!
let y1X = 50, y1Y = 0;
let y2X = 100, y2Y = 0;
let y3X = 150, y3Y = 0;
let y4X = 200, y4Y = 0;
let y5X = 250, y5Y = 0;

// draw() içinde:
y1Y += 2; circle(y1X, y1Y, 10);
y2Y += 2; circle(y2X, y2Y, 10);
y3Y += 2; circle(y3X, y3Y, 10);
y4Y += 2; circle(y4X, y4Y, 10);
y5Y += 2; circle(y5X, y5Y, 10);

// 100 yıldız için 200 değişken! 🤯

😫 Her yıldız için 2 değişken + 2 satır kod

 
// Tüm x'ler bir dizide, y'ler bir dizide
let yildizX = [50, 100, 150, 200, 250];
let yildizY = [0, 0, 0, 0, 0];

// draw() içinde - 5 veya 100 farketmez!
for (let i = 0; i < yildizX.length; i++) {
  yildizY[i] += 2;
  circle(yildizX[i], yildizY[i], 10);
}

// 100 yıldız için sadece 2 dizi!

🎉 Kaç yıldız olursa olsun aynı kod!

Dizilerin 5 Büyük Faydası

  • 📦 Organize: İlişkili verileri bir arada tut
  • 🔢 Ölçeklenebilir: 5 veya 5000 eleman - kod aynı
  • 🔄 Döngü Uyumu: for ile tüm elemanları gez
  • ➕ Dinamik: Çalışma anında eleman ekle/sil
  • 🎮 Oyun Mekaniği: Düşman listesi, envanter, skor tablosu
💡 Oyun Örnekleri
  • Space Invaders: dusmanlar[], mermiler[]
  • Flappy Bird: borular[]
  • Snake: yilanParcalari[]
  • Tetris: bloklar[][] (2D dizi)

Dizi Oluşturma

// Boş dizi
let renkler = [];

// Değerlerle dizi
let sayilar = [10, 20, 30, 40, 50];
let meyveler = ["elma", "armut", "muz"];
let karisik = [42, "merhaba", true, 3.14];

Elemanlara Erişim

Dizilerde her eleman bir index (sıra numarası) ile işaretlenir. Önemli nokta: index'ler 0'dan başlar, 1'den değil! Bu programlamada evrensel bir kuraldır.

Bir elemanı okumak için dizi[index] yazarsın. Örneğin meyveler[0] ilk elemanı, meyveler[2] üçüncü elemanı verir. Son elemana ulaşmak için dizi[dizi.length - 1] kullanılır çünkü index 0'dan başladığı için son elemanın index'i uzunluktan 1 eksiktir. 

let meyveler = ["elma", "armut", "muz"];
//               [0]      [1]     [2]

console.log(meyveler[0]);  // "elma"
console.log(meyveler[1]);  // "armut"
console.log(meyveler[2]);  // "muz"

// Değiştirme
meyveler[1] = "çilek";  // armut → çilek

// Uzunluk
console.log(meyveler.length);  // 3
⚠️ Dikkat!

Diziler 0'dan başlar! İlk eleman [0], son eleman [uzunluk - 1] index'indedir.

Dizi Metodları

JavaScript dizileri güçlü metodlar (hazır fonksiyonlar) sunar. En sık kullanılanlar: push() (sona ekle), pop() (sondan çıkar), length (uzunluk). Bu metodlar sayesinde dizilere dinamik olarak eleman ekleyip çıkarabilirsin - oyunlarda düşman öldüğünde listeden silmek gibi!

Metod Açıklama Örnek
push(eleman) Sona eleman ekler dizi.push("yeni")
pop() Sondan eleman çıkarır ve döner let son = dizi.pop()
shift() Baştan eleman çıkarır ve döner let ilk = dizi.shift()
unshift(eleman) Başa eleman ekler dizi.unshift("ilk")
splice(i, n) i. indexten n eleman siler dizi.splice(2, 1)
includes(eleman) Eleman var mı kontrol eder dizi.includes("elma") → true/false
indexOf(eleman) Elemanın indexini döner dizi.indexOf("elma") → 2
length Dizi uzunluğu (eleman sayısı) dizi.length → 5

Döngü ile Diziler

Dizilerin gerçek gücü döngülerle ortaya çıkar! for döngüsü ile tüm elemanları tek tek gezebilirsin. i değişkeni 0'dan başlayıp dizi.length'e kadar gider, böylece dizi[i] ile her elemana sırayla erişirsin.

for...of döngüsü daha kısa bir alternatif: index ile uğraşmadan doğrudan elemanlara erişirsin. Ama elemanı değiştirmek veya index'i bilmek istersen klasik for döngüsü gerekir. 

let renkler = ["kırmızı", "yeşil", "mavi"];

// for döngüsü
for (let i = 0; i < renkler.length; i++) {
  console.log(renkler[i]);
}

// for...of döngüsü (daha kolay)
for (let renk of renkler) {
  console.log(renk);
}
