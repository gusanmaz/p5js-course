Ders 3: Değişkenler

📚 Temel Kavramlar ⏱️ 50 dakika 🎯 Veri Saklama

Değişken Nedir?

Değişken, programlama dünyasının en temel kavramlarından biridir. Basitçe söylemek gerekirse, değişken bir değeri saklamak için kullandığımız kutucuktur.

🧠 Gerçek Hayat Benzetmesi

Bir değişkeni, üzerinde etiket olan bir kutu gibi düşünebilirsiniz. Kutunun içine bir değer koyarsınız ve daha sonra etiketi kullanarak o değere ulaşırsınız.

  • 📦 Kutu = Değişken (bellek alanı)
  • 🏷️ Etiket = Değişken adı
  • 🔢 İçindeki şey = Değer

Neden Değişken Kullanırız?

  • Değerleri saklamak: Bir sayı, metin veya durumu hafızada tutmak
  • Kod tekrarını azaltmak: Aynı değeri birçok yerde kullanmak
  • Dinamik davranış: Değerleri program çalışırken değiştirmek
  • Okunabilirlik: genislik yazmak, 400 yazmaktan daha anlaşılır

Değişken Tanımlama

JavaScript'te (ve dolayısıyla p5.js'te) değişken tanımlamak için let anahtar kelimesini kullanırız. 

let degiskenAdi = deger;

Örnekler

let yas = 25;              // Sayı
let isim = "Ahmet";        // Metin (string)
let ogrenciMi = true;      // Boolean (true/false)
let x = 100;               // Koordinat
let hiz = 5.5;             // Ondalıklı sayı
💡 let vs const vs var

let: Değeri değişebilen değişkenler için (en çok kullanılan)
const: Sabit değerler için (değiştirilemez)
var: Eski yöntem (artık kullanılması önerilmez)

İsimlendirme Kuralları

  • ✅ Harfle başlamalı: daire, x1
  • ✅ Alt çizgi veya $ ile başlayabilir: _toplam, $fiyat
  • ❌ Rakamla başlayamaz: 1deger hatalı!
  • ❌ Boşluk içeremez: benim degiskenim hatalı!
  • ❌ Özel karakterler kullanılamaz: deger-1, toplam@ hatalı!
  • ⚠️ Büyük/küçük harf duyarlı: Deger ile deger farklıdır

Camel Case Yazım Stili

JavaScript'te birden fazla kelimeden oluşan değişken isimleri için camelCase kullanılır: 

let topCapi = 80;
let oyuncuPuani = 0;
let oyunBittiMi = false;
let enYuksekSkor = 100;

Veri Tipleri

JavaScript'te değerler farklı türlerde olabilir. En yaygın kullanılan veri tipleri:

Veri Tipi Açıklama Örnekler
Number (Sayı) Tamsayılar ve ondalıklı sayılar let sayi = 42;
let pi = 3.14;
let negatif = -10;
String (Metin) Tırnak içinde yazılan metinler let isim = "Ayşe";
let mesaj = 'Merhaba!';
let cumle = `Yaş: ${yas}`;
Boolean (Mantıksal) Sadece true veya false let acikMi = true;
let oyunBitti = false;
Undefined / Null Değer atanmamış veya boş let x; → undefined
let y = null; → boş

Dinamik ve Statik Tip Sistemleri

Programlama dilleri, değişken tiplerini nasıl ele aldıklarına göre iki ana kategoriye ayrılır:

🔄 Dinamik Tipli Diller (JavaScript, Python, Ruby)

JavaScript dinamik tipli bir dildir. Bu ne demek?

  • Değişken tipini önceden belirtmek zorunda değilsiniz
  • Tip, atanan değerden otomatik olarak anlaşılır
  • Aynı değişkene farklı tipte değerler atanabilir
// JavaScript - tip belirtmeye gerek yok
let x = 42;        // x şu an Number
x = "merhaba";     // x artık String oldu! (hata vermez)
x = true;          // x artık Boolean oldu!

🔒 Statik Tipli Diller (Java, C, C++, C#, TypeScript)

Bu dillerde değişkenin tipi önceden açıkça belirtilmeli (explicit typing) ve değişken ömrü boyunca aynı tipte kalır. 

// Java - tip açıkça belirtilmeli
int sayi = 42;           // sayi sadece int olabilir
String isim = "Ayşe";    // isim sadece String olabilir
sayi = "merhaba";        // HATA! int değişkene String atanamaz
// C - benzer şekilde
int x = 10;
float pi = 3.14f;
char harf = 'A';
Özellik Dinamik Tipli (JS) Statik Tipli (Java, C)
Tip belirtme Otomatik (implicit) Zorunlu (explicit)
Tip değişimi ✅ İzin verilir ❌ İzin verilmez
Hata tespiti Çalışma zamanında Derleme zamanında
Esneklik ✅ Yüksek ⚠️ Düşük
Güvenlik ⚠️ Riskli olabilir ✅ Daha güvenli

typeof Operatörü

JavaScript'te bir değişkenin mevcut tipini öğrenmek için typeof operatörü kullanılır. Bu özellikle dinamik tipli dillerde çok önemlidir çünkü değişkenin tipi çalışma sırasında değişebilir.

Değer typeof Sonucu Açıklama
42 veya 3.14 "number" Tüm sayılar (tamsayı, ondalık)
"merhaba" "string" Metin değerleri
true veya false "boolean" Mantıksal değerler
undefined "undefined" Değer atanmamış
null "object" ⚠️ Tarihi bir hata! (aslında null)
[1, 2, 3] "object" Diziler de object döner
function() {} "function" Fonksiyonlar

💡 typeof Ne İşe Yarar?

  • Hata ayıklama: Beklenmeyen tip hatalarını bulmak
  • Güvenli kod: İşlem yapmadan önce tipi kontrol etmek
  • Dinamik davranış: Tipe göre farklı işlemler yapmak
// Örnek: Güvenli toplama
let a = 5;
let b = "10";

// Dikkat! b aslında string
console.log(typeof a);  // "number"
console.log(typeof b);  // "string"
console.log(a + b);     // "510" (string birleştirme!)
console.log(a + Number(b)); // 15 (doğru toplama)

Global ve Lokal Değişkenler

Değişkenlerin kapsamı (scope), onlara kodun hangi bölümlerinden erişilebileceğini belirler. Bu, programlamanın en önemli kavramlarından biridir.

🌍 Global Değişkenler

Fonksiyonların dışında tanımlanan değişkenlerdir. Programın her yerinden erişilebilir ve değiştirilebilir.

✅ Ne zaman global kullanmalı?

  • Birden fazla fonksiyon aynı değere erişmeli (örn: oyuncu skoru)
  • Değer setup() ile draw() arasında paylaşılmalı
  • Program boyunca değer korunmalı (örn: oyun durumu)
// ✅ GLOBAL - Fonksiyonların dışında
let skor = 0;        // Her yerden erişilebilir
let oyuncuX = 200;   // setup ve draw'da kullanılacak
let canliMi = true;  // Oyun durumu

function setup() {
  createCanvas(400, 400);
  // skor, oyuncuX, canliMi burada erişilebilir
}

function draw() {
  // skor, oyuncuX, canliMi burada da erişilebilir
  oyuncuX = oyuncuX + 1;  // Global değişkeni değiştir
}

function mousePressed() {
  // Burada da erişilebilir
  skor = skor + 10;
}

📦 Lokal Değişkenler

Fonksiyonların içinde tanımlanan değişkenlerdir. Sadece tanımlandıkları fonksiyon içinde erişilebilir.

✅ Ne zaman lokal kullanmalı?

  • Değer sadece o fonksiyonda gerekli (örn: geçici hesaplama)
  • Her çağrıda sıfırdan başlaması gereken değerler
  • Döngü sayaçları ve geçici değişkenler
function draw() {
  background(220);
  
  // ✅ LOKAL - Sadece draw() içinde var
  let x = mouseX;      // Her frame yeniden oluşturulur
  let y = mouseY;      // Sadece burada erişilebilir
  let cap = 50;        // Geçici değer
  
  circle(x, y, cap);
}

function mousePressed() {
  // ❌ HATA! x, y, cap burada tanımlı değil
  // console.log(x);  // ReferenceError!
}

⏱️ Değişken Ömrü (Lifetime)

Tür Oluşturulma Yok Olma Ömür
Global Program başladığında Program kapandığında Tüm program süresi
Lokal Fonksiyon çağrıldığında Fonksiyon bittiğinde Sadece fonksiyon süresi

🎮 Oyun Örneği: Global vs Lokal

// === GLOBAL DEĞİŞKENLER ===
// Bunlar program boyunca yaşar
let topX = 200;      // Topun X konumu (korunmalı)
let topY = 200;      // Topun Y konumu (korunmalı)
let hiz = 3;         // Hareket hızı (paylaşılmalı)
let skor = 0;        // Oyuncu skoru (korunmalı)

function setup() {
  createCanvas(400, 400);
}

function draw() {
  background(30);
  
  // === LOKAL DEĞİŞKENLER ===
  // Bunlar her frame yeniden hesaplanır
  let mesafe = dist(mouseX, mouseY, topX, topY);
  let yakalandi = mesafe < 25;
  
  // Global değişkenleri güncelle
  topX = topX + hiz;
  
  // Sınır kontrolü
  if (topX > 400) topX = 0;
  
  // Topu çiz
  fill(yakalandi ? 'green' : 'red');
  circle(topX, topY, 50);
  
  // Skor göster
  fill(255);
  text("Skor: " + skor, 20, 30);
}

function mousePressed() {
  // Lokal: sadece bu fonksiyonda
  let mesafe = dist(mouseX, mouseY, topX, topY);
  
  if (mesafe < 25) {
    skor = skor + 10;  // Global'i değiştir
  }
}

⚠️ Sık Yapılan Hatalar

// ❌ HATA 1: draw() içinde tanımlayıp değeri korumaya çalışmak
function draw() {
  let x = 0;   // Her frame 0'dan başlar!
  x = x + 1;   // Hep 1 olur, artmaz
  circle(x, 200, 50);  // Top hiç hareket etmez
}

// ✅ DOĞRU: Global tanımla
let x = 0;
function draw() {
  x = x + 1;   // Artık gerçekten artar
  circle(x, 200, 50);  // Top hareket eder
}
// ❌ HATA 2: Aynı isimde global ve lokal
let renk = 'red';  // Global

function draw() {
  let renk = 'blue';  // Lokal - global'i gölgeler!
  fill(renk);         // 'blue' kullanır
}
// Global 'renk' hâlâ 'red'

p5.js Sistem Değişkenleri

p5.js, hazır olarak tanımlanmış birçok sistem değişkeni sunar. Bunları tanımlamanıza gerek yok, doğrudan kullanabilirsiniz!

Kategori Değişken Açıklama
Tuval width Tuval genişliği (piksel)
height Tuval yüksekliği (piksel)
Fare mouseX Farenin X koordinatı
mouseY Farenin Y koordinatı
mouseIsPressed Fare tıklanıyor mu? (true/false)
mouseButton Hangi tuş? (LEFT, RIGHT, CENTER)
Zaman frameCount Başlangıçtan beri toplam kare sayısı
deltaTime Kareler arası geçen süre (ms)

🧪 Deney Zamanı!

  • width/2 ve height/2 kullanarak daireyi tam ortaya konumlandırın
  • Fare konumunu ekranda gösterin
  • frameCount ile bir sayaç yapın

Aritmetik İşlemler

Değişkenlerle matematiksel işlemler yapabilirsiniz:

Temel İşlemler

Operatör İşlem Örnek Sonuç
+ Toplama 10 + 3 13
- Çıkarma 10 - 3 7
* Çarpma 10 * 3 30
/ Bölme 10 / 3 3.33...
% Mod (kalan) 10 % 3 1

Kısayol İşlemler

Kısayol Anlamı Örnek (x = 10) x'in Yeni Değeri
x += 5 x = x + 5 10 + 5 15
x -= 3 x = x - 3 15 - 3 12
x *= 2 x = x * 2 12 * 2 24
x /= 4 x = x / 4 24 / 4 6
x++ x = x + 1 6 + 1 7
x-- x = x - 1 7 - 1 6

Mod İşlemi (%)

Mod işlemi, bölme işleminden kalanı verir. Bu çok yararlı bir işlemdir!

İfade Hesaplama Sonuç Açıklama
10 % 3 10 ÷ 3 = 3 kalan... 1 3×3=9, 10-9=1
15 % 5 15 ÷ 5 = 3 kalan... 0 Tam bölünüyor
7 % 2 7 ÷ 2 = 3 kalan... 1 Tek sayı!
8 % 2 8 ÷ 2 = 4 kalan... 0 Çift sayı!
💡 Mod İşleminin Kullanım Alanları
  • Tek/Çift kontrolü: sayi % 2 == 0 ise çift
  • Döngüsel animasyon: frameCount % 60 0-59 arası değişir
  • Ekran sınırına geri dönme: x % width
